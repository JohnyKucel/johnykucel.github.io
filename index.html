Squeek Merge PlannerFlagship

A planner for Squeekchain Genesis holders. It calculates which Squeeks can merge right now, what level the merged result reaches, and how many more you need to hit your target — so merges can be planned instead of guessed. Single-file HTML web app, no backend, no wallet connection.
